# 🪙 Coin Catcher — 2D Arcade Game

A fun, retro-inspired 2D arcade game built with **HTML5 Canvas, CSS3, and Vanilla JavaScript**. Collect gold coins, avoid the enemy, beat your high score, and see how long you can survive!

🎮 **[Play the Game Live](https://dimplee14.github.io/coin-catcher-game/)**

## ✨ Features

- 🕹️ **Smooth Player Movement** — Move using Arrow Keys or WASD.
- 🪙 **Coin Collection** — Collect coins and increase your score.
- 👾 **Enemy Patrol AI** — Avoid the moving red enemy.
- ❤️ **Lives System** — Start with 3 lives.
- 🛡️ **Temporary Invulnerability** — Get brief protection after taking damage.
- 🏆 **High Score Tracking** — Save your best score using browser localStorage.
- ⚡ **Combo Multipliers** — Collect coins quickly to increase your multiplier.
- 📈 **Dynamic Difficulty** — The enemy gets faster as your score increases.
- ⏸️ **Pause & Resume** — Pause or continue using `P`, `ESC`, or the Pause button.
- 🔊 **Sound Effects** — Optional arcade-style sounds with a sound toggle.
- 📱 **Mobile Controls** — Play using the on-screen directional pad.
- 🎨 **Arcade Visual Effects** — Coin glow, score popups, particles, and screen shake.
- ♿ **Accessibility & Responsive Design** — Responsive layout, keyboard focus indicators, and reduced-motion support.

## 🕹️ How to Play

1. Open the game using the live demo link.
2. Click **Start Game**.
3. Move your player and collect as many gold coins as possible.
4. Avoid the moving red enemy.
5. Use your lives wisely and try to beat your best score!

### Controls

| Action | Control |
|---|---|
| Move | Arrow Keys or WASD |
| Pause / Resume | `P` or `ESC` |
| Toggle Sound | Sound button |
| Mobile Movement | On-screen directional pad |
| Restart | Restart button |

## 🛠️ Technologies Used

- **HTML5** — Game structure and canvas.
- **CSS3** — Styling, responsive layout, and visual effects.
- **Vanilla JavaScript** — Game logic, movement, collision detection, and scoring.
- **HTML5 Canvas API** — Rendering the game.
- **Web Audio API** — Generating sound effects.
- **localStorage** — Saving the best score.
- **GitHub Pages** — Hosting the live game.

**No external JavaScript libraries or frameworks are required.**

## 🚀 Run Locally

You can run the game on your computer without installing any dependencies.

1. Clone this repository:

   ```bash
   git clone https://github.com/dimplee14/coin-catcher-game.git
   ```

2. Open the project folder:

   ```bash
   cd coin-catcher-game
   ```

3. Open `index.html` in your browser.

Alternatively, use a code editor such as Visual Studio Code and open the project with a local development server.
